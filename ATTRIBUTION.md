# Attribution for native Hindi reference datasets

The following datasets contain extracts from Hindi Wikipedia, contributed by Hindi Wikipedia editors and released under the **Creative Commons Attribution-ShareAlike 4.0 International** license:

https://creativecommons.org/licenses/by-sa/4.0/

| Dataset | Source |
|---|---|
| `hi-kshetriya-pakshailiyan` | https://hi.wikipedia.org/wiki/भारतीय_खाना |
| `hi-hindustani-rag` | https://hi.wikipedia.org/wiki/श्रेणी:राग and each row's article link |
| `hi-aitihasik-rajvansh` | https://hi.wikipedia.org/wiki/श्रेणी:भारत_के_राजवंश and each row's article link |
| `hi-bharatiya-govansh-naslen` | https://hi.wikipedia.org/wiki/गाय |
| `hi-bharatiya-adhiniyam-sandarbh` | https://hi.wikipedia.org/wiki/श्रेणी:भारत_के_अधिनियम and each row's article link |

Each row contains its source URL; article extracts include permanent revision links when available. The source page histories provide contributor attribution.

Changes: selected records and opening paragraphs were extracted from HTML; reference markers and extra whitespace were removed; lists were flattened. Row values were not translated. Titles and dataset descriptions were written in Hindi. Retrieved 2026-10-22.

The license applies to these five adapted datasets, including their JSON, CSV and XLSX distributions. It does not change the licenses of other datasets in this repository. Any English words, spelling, dates, or historical statements appearing inside the source Hindi text are preserved from the source. These collections are selected reference extracts, not exhaustive or authoritative registers; legislation may be historical, repealed, or a bill rather than enacted law.
